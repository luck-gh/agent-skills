# 可选迭代目标

仅明确要求创建或补充 GOAL 时读取,与证据及安全规则共同使用.不加载四文件基线或语言规范.

迭代批次的目标入口默认是项目根相对路径 `docs/GOAL.md`;用户显式指定路径或项目已有明确目标入口时,沿用该准确路径,不迁移文档或再建一份 GOAL.同一批次始终复用它.仅保留批次目标与范围,可观察的验收标准,未完成项及停止边界;实现和验收详情指向已有真源,不复制 PLAN 或逐轮聊天与测试日志.未知目标不猜测,未验收项不能标完成.

普通初始化仍只建立四份基线.迭代执行时,缺失的 GOAL 由首轮新 Codex 任务在实施前创建,后续轮次维护同一入口;本 Skill 只在用户明确请求时提前创建或补充该文档,不创建执行任务或接力.写入前固定授权目标,读取其有效指令与已有内容,检查目标及父目录的原始名称和类型,只允许缺失或普通文件/目录;大小写冲突,链接,reparse,broken path 或职责冲突时停止.保留有效内容及用户改动,写后回读;失败时报告已写和未写状态.

GOAL 已存在或本次获准建立时,在获准维护的 AGENTS 中只加入迭代任务按需读取的入口;PLAN 需要导航时只留指针,不维护第二份批次状态.只建 GOAL 不自动补建或修改其他基线,普通任务也不必加载 GOAL.
