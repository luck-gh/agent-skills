# Verilog 与 SystemVerilog 边界

仅为 Verilog/SystemVerilog RTL 或验证组件建立或校准规范时读取.先确定 RTL 与 testbench 职责,时钟/复位域,协议和仿真/综合约束,不套用软件的异常与资源回收模型.

- 防御以规格明确的外部协议条件为边界.非法输入的拒绝,错误标志或恢复只有规格要求时才实现;不额外增加复位,非法状态自恢复或默认成功输出来掩盖设计错误.
- CDC 同步,必要的复位域处理,组合逻辑完整赋值及 `case` 完整性属于正确性要求,不能作为冗余防御删除.复位极性,同步/异步方式及释放要求来自设计规格,不继承参考项目的固定选择.
- 组合路径通过前置赋值或完整分支覆盖输出,避免非预期锁存器.默认赋值必须符合设计含义;`default` 分支不自动等于返回 idle 或复位.先前已完整赋值时允许按项目规范使用空 default,但仍需暴露应诊断的非法状态.
- `unique`/`priority` 的仿真检查和综合含义须与实际工具配置匹配,不能当作所有未知值及非法状态均已处理的证明.不以 `casex` 或随意吞掉 X/Z 使仿真看似正常;通配匹配仅按真实编码语义使用.
- 断言用于表达协议和不变量,其使能与禁用条件沿真实 reset/valid 契约,不靠关闭断言掩盖失败.区分 testbench 检查与综合硬件行为,仿真通过不等于 CDC,时序或目标硬件验证通过.
- 生成规则保留现有 lint,仿真,综合,时序与实机入口中适用的部分.工具缺失或未运行就记录验证缺口,不为建档新增复位逻辑,测试平台或工具配置.
