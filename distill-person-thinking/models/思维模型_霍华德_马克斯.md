# Howard Marks 思维模型

## Best used for
- 共识交易审查,信用风险,市场情绪与投资攻守取舍.

## Do not use for
- 日内择时,把逆向投资等同于逢跌必买,在缺市场信息时硬判周期.

## Core models

### second-level-pricing: 共识定价的第二层思考
- Definition: 投资结果取决于实际情况相对价格所含预期的差异,正确描述一家企业仍可能买得太贵.
- Use when: 推论停在行业很好,公司优秀,因此应买入.
- Procedure: 写出基本面情景;辨认价格依赖什么预期;先复述共识最有力的理由,再定位其具体错误与价格影响;陈述自己与共识的差别及依据;同时推演共识正确和自己错误时的后果;差异已修复或没有可信优势时接受不行动.
- Signals: 估值隐含增长,一致预期,拥挤行为,坏情景下损失,偏离共识的证据.
- Evidence: S01, S02
- Limits: 与多数人不同不代表更正确;推测的市场预期要标明推断,不能伪造可测的群体信念.
- Confidence: high

### market-temperature: 市场温度与攻守姿态
- Definition: 观察当下投融资条件中的乐观或恐惧及其价格后果,据此改变风险暴露和资金使用节奏.
- Use when: 风险溢价很低仍争相放贷,或恐慌让优先索偿权也被抛售.
- Procedure: 检查价格,融资条款和风险补偿;用真实成交而非单纯涨跌验证情绪;分开经营改善,估值变化和融资成本带来的历史收益;核查索偿顺位,资产保护与资金期限;比较损失承受能力与机会成本;选择更防守,保持或逐步进取,中间状态不强行择时;写明哪些信号会改变姿态.
- Signals: 信用利差,杠杆,契约保护,融资可得性,被迫卖出,过度确定的叙事.
- Evidence: S01, S02, S03
- Limits: 温度不是转折时钟;早判断可能长期承受机会成本.五次成功判断是本人选择的回顾,不代表完整择时胜率.2008 年另有基金接近追加保证金,说明恐慌机会仍须与偿付能力和资金期限分开核验.更高票息也可能伴随更高违约损失.
- Confidence: high

## Decision heuristics
- 人人认同好前景 -> 查价格是否已反映 -> 缺预期差不能靠名气补足. [S01]
- 便宜来自恐慌 -> 核查资产质量与下行保护 -> 不能存活的资产仍应排除. [S02]

## Tensions
- 不做宏观择时与调整风险姿态并存:调整依据是当前条件,不是猜明天发生什么.
- 错失机会也有成本,但不能用它合理化无法承受的损失.

## Unknowns
- 历史危机案例不提供今天的周期位置;不同信用工具的回收率与流动性必须单独研究.
