# Charlie Munger 思维模型

## Best used for
- 复杂商业问题,激励设计,多种解释的交叉检验与错误预防.

## Do not use for
- 用人物名气否定专业证据,把多模型分析写成名词堆砌或人身评价.

## Core models

### latticework-and-inversion: 多学科交叉检验与逆向排除
- Definition: 同一现象可能由经济约束,心理机制与规模效应共同形成;通过反向排除减少单一工具造成的盲点.
- Use when: 现有解释只能说明一部分事实,或把结果全部归因于某个英雄.
- Procedure: 写出待解释事实与硬约束;分别检查客观利益和心理偏差;选少数真正相关的机制,注明观察,本人推测与当前假设;检查是少数变量占优,多个因素相互加强还是外部浪潮;反问哪些条件使结果不可能或导致失败;用能区分解释的数据淘汰假设.此顺序为应用归纳.
- Signals: 单因解释遗漏的事实,规模与成本关系,利益结构,可观察的反例,多个因素的相互作用.
- Evidence: S01, S02
- Limits: 类比只生成假设;跨领域术语不能证明因果.Les Schwab 的成功原因部分是演讲中的推测,并非完成因果调查.逆向排除依赖约束真实,否则会删去正确答案.避免为了凑模型忽视更直接的解释.
- Confidence: medium

### incentives-before-exhortation: 先查激励再劝说
- Definition: 组织奖励的行为可能与口头目标相反,奖励还会改变当事人对事实的解释.
- Use when: 培训与劝告反复无效,指标改善却损害真实结果.
- Procedure: 标出付款者,推荐者,使用者和损失承担者;按现行奖励推演最有利的行为;检查价格是改变质量信号还是增加中间人利益;调整可控的奖励和约束;像 FedEx 完成结果激励那样对准关键交接,再核对质量与下游负担,防止指标改善掩盖真实损害.
- Signals: 报酬与结果脱节,付费建议者的利益,被奖励的代理指标,短期收益与滞后损失.
- Evidence: S01, S02
- Limits: 利益冲突提示应核验,不能自动证明欺诈;激励也不能替代能力,资源或合法程序.
- Confidence: medium

## Decision heuristics
- 解释过于整齐 -> 换一种有依据的因果视角并逆向检查 -> 没有额外解释力就不保留. [S02]
- 人总是做出同类坏结果 -> 先看制度实际奖励什么 -> 修改后核对质量与副作用. [S01]

## Tensions
- 跨学科广度与具体领域的能力边界必须同时保留.
- 强激励能提高执行,也会增加对指标的迎合;需要检查整体结果.
