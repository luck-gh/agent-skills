# 乔治·索罗斯思维模型

## Best used for
- 解释融资,价格,政策与行业基本面相互强化的过程;寻找叙事失效的具体环节.
- 在方案比较中检验一个看对方向的方案是否仍可能因路径风险失败.

## Do not use for
- 把所有趋势都叫泡沫,把发现泡沫直接当作做空时点,假定自己必然比市场正确.
- 将特定年代政治观点或交易行为代入本人对当前事件的真实立场.

## Core models

### reflexive-feedback: 预期与现实的反身循环
- Definition: 参与者的理解并不完整,其行为却能改变所理解的现实.金融价格通过融资,抵押品或政策反应影响基本面,再改变参与者预期.
- Use when: 行业增长和市场信心看似互相证明,需要判断两者是否依赖同一反馈链.
- Procedure: 分开列出可观察事实与主流信念;写出信念到行动再到基本面的具体路径;核对所谓验证是否由该信念推动的融资自身制造;把政策制定者的权限,激励和反应时滞纳入反馈;找出约束和反向反馈;分别构造继续强化,被抑制及反转的条件.步骤为公开理论的当前操作化.
- Signals: 抵押品与授信同步扩张,高估值支持并购或融资,实际现金流跟不上预期,政策反应改变参与者行为.
- Evidence: S01, S02, S03
- Limits: 单向相关或外部冲击不自动构成反身性,信息不对称和利益冲突也会制造不确定.循环长度和转折时间不可据此精确预测,负反馈或政策可能中断过程,泡沫只是其中一种表现.
- Confidence: high

### uncertainty-sized-commitment: 让承诺规模适应不确定性
- Definition: 判断大方向与承受实现路径是两个问题;在远离常态的环境中,不确定性的范围本身也会变化,需要给承诺规模留余地.
- Use when: 一个方案终局有吸引力,但中途融资,波动或资源消耗可能迫使退出.
- Procedure: 区分终局判断和到达路径;列出会迫使退出的资源约束;模拟超出历史常态的波动及反馈反转;将承诺缩至能承受错误路径的范围;事先写明重新评估条件.此处资源预算属于当前外推,不是其私有仓位公式.
- Signals: 波动扩大,流动性减少,追加保证金或融资需求,被迫处置,旧统计关系失效,约束接近阈值.
- Evidence: S02, S03
- Limits: 源于本人对 2008 年方向正确但仓位过大的失败解释.没有保证安全的固定规模;非金融项目的外推须标注,不可替代工程安全分析.
- Confidence: medium

## Decision heuristics
- 价格上涨同时改善融资条件 -> 检查增长是否依赖持续涨价 -> 撤去融资反馈后无法维持时降低对基本面的独立信任. [S02]
- 方向看对却不断被迫退出 -> 优先检查承诺规模和路径假设 -> 不用加大投入证明原判断正确. [S02]
- 政策出台 -> 同时检查政策制定者与市场参与者的误判 -> 不把政策当作外生且必然有效的常量. [S02, S03]

## Tensions
- 认识到泡沫可能继续强化,并不等于应该参与;参与获利与反转生存需要分开评估.
- 理论帮助解释机制,却不能消除预测不确定性;历史叙事的流畅性不能证明实时判断准确.
- 同一政策在不同融资与需求环境下可能反向作用;不能将过去奏效的名称当成当前有效性证据. [S03]

## Unknowns
- 未核验其私人交易记录,精确止损与加仓方法或当前持仓.没有采纳社区版本中缺乏原始证据的固定试仓/加码规则.
