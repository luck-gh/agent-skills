# 张忠谋思维模型

## Best used for
- 制造产业分工,平台与客户关系,研发转量产,工艺投入的商业验证.

## Do not use for
- 依据历史口述推测当前制程参数,产能或产业政策,把单家企业成功等同于整个代工行业必然成功.

## Core models

### specialization-with-customer-trust: 专业分工与客户信任
- Definition: 选择能够建立优势的环节,同时让上下游有理由长期合作;不做什么也是业务契约的一部分.
- Use when: 团队试图复制全产业链,但研发,设计,制造与销售能力分布明显不均.
- Procedure: 列出价值链,区分已证明能力与潜在优势;寻找伙伴有需求却难以自行承担的环节;检验分工后的接口与利益冲突;用质量交付证明承诺;区分临时溢出订单,原厂不愿承担的业务与长期客户需求,分别验证稳定性和盈利条件.客户数量增加后仍核对需求是否同受一个周期影响.
- Signals: 客户受阻原因,互补能力,竞争冲突,重复订单,资格验证,临时溢出订单占比.
- Evidence: S01, S02
- Limits: 专业化不自动创造市场.张忠谋在口述中承认最初只是期待无晶圆厂产业成长,早期大厂余量订单并不稳定;中立承诺也不能替代技术交付.
- Confidence: high

### manufacturing-to-economic-value: 制造能力到经济价值的闭环
- Definition: 技术知识必须经过合格产出,规模化和客户采用,才转化为可持续经济价值.
- Use when: 实验室结果很好,量产却持续报废,成本偏高或无法支撑客户上市.
- Procedure: 将目标拆成性能,良率,单位合格品成本与交付;寻找限制产出的物理或流程原因;开展有依据的工艺验证;分别跟踪实验成功,研发转制造,客户验证,量产和收入;独立检验成本学习假设,只有实测改善才能支持降价与后续投入,不能用量产计划代替完成记录.
- Signals: 合格产出,失效原因,单位成本,研发转制造进度,客户试产与量产采用,产能利用.
- Evidence: S01, S02
- Limits: 历史学习曲线不是固定降本规律.不能把张忠谋早期工艺经验当成当前制造参数,也不能为达成本目标跳过质量要求.
- Confidence: high

## Decision heuristics
- 想把设计制造销售全做完 -> 按能力和客户障碍拆开 -> 证明所选环节能独立创造价值. [S01]
- 工艺指标改善 -> 跟踪合格产出与客户量产 -> 区分研发成功和商业交付. [S01, S02]

## Tensions
- 聚焦制造有利于建立合作信任,但需要持续投资才能承接客户不同技术需求.
- 提前建设能力可能催生新市场,也可能长期面对不稳定订单;不能事后抹去这一不确定性.

## Unknowns
- 未核验完整回忆录,私人决策资料或退休后的经营观点;历史年报中的未来计划不视为已完成结果.
