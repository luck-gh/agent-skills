# Donald Trump 思维模型

## Best used for
- 一般商业谈判中检查双方利益,替代方案与成交条件,避免把对方开价当唯一可行路径.

## Do not use for
- 预测当代政治行动,定向政治劝服,威胁骚扰,欺骗性报价,把任何关系都视为零和博弈.

## Core models

### counterparty-payoffs: 从对手的替代成本寻找议价空间
- Definition: 除了自己的愿望,也算对方不成交需要承担什么,并保留自己能实际采取的其他路径,据此识别可交换条件.
- Use when: 对方显得占绝对优势,但拒绝交易同样会给其增加成本.
- Procedure: 列出双方的成交收益和不成交代价;核实自己的真实替代方案;找可交换的价格,期限或履约条件;提出可执行的组合并观察反馈;超出底线则退出或改走替代路径.这是当前操作化,不是本人原文步骤.
- Signals: 对方持有或处置资产的成本,期限压力,真实授权范围,双方替代方案的可行性.
- Evidence: S01 的交易备选自述,S02 对对手处置成本的直接解释;两份本地摘要保留材料范围及当前推导的区分.
- Limits: 对方可能重视声誉,规则或长期关系而非眼前收益;若对方无调整权限或可低成本转手,需重新判断协商空间.虚构筹码会损害信任.这里只证明公开表达过这种思路,不证明其商业实践总能成功.
- Confidence: medium

## Decision heuristics
- 被单一路径锁住 -> 同时核对继续,转让与退出是否真实可行 -> 不把尚未获得的机会当筹码. [S01]
- 收到看似最终条件 -> 检查对方接受调整是否比拒绝更有利 -> 规则或权利不可交易时停止此推演. [S02]
- 把强硬当唯一风格 -> 根据对方行为和关系选择语气 -> 不以羞辱或威胁代替条件谈判. [S02]

## Tensions
- 强硬表达与保留合作空间可能冲突;短期让步不等于长期收益.
- 回忆录的自我呈现与客观交易结果不是同一证据,不能从成功叙述推导通用胜率.

## Unknowns
- 不覆盖本人全部商业思维,私人意图或当前政策.案例来自本人及合著者叙述,未独立审计其交易盈亏.
