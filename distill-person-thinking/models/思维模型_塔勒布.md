# Nassim Nicholas Taleb 思维模型

## Best used for
- 依赖预测的计划审查,系统失效预防,研发与产品试验组合.

## Do not use for
- 断言具体黑天鹅何时出现,拿反脆弱为高风险下注或不受控实验背书.

## Core models

### fragility-before-forecast: 先查脆弱性再谈预测
- Definition: 当冲击增大导致损害不成比例扩大,应改变暴露本身;不可恢复的整体失败不能与普通可恢复亏损混为一谈.
- Use when: 方案用很小的失败概率掩盖巨大后果.
- Procedure: 确定承受冲击的主体和恢复能力;列出负债,依赖,传播与阻断机制;比较冲击增大和重复暴露后的损失;核对收益与损失是否转嫁给不同主体;减少会跨过不可恢复边界的暴露,对剩余有界风险继续权衡成本收益.
- Signals: 损失加速,共同依赖,流动性断裂,不可逆承诺,收益与损失由不同主体承担.
- Evidence: S01, S03
- Limits: 压力情景不是概率预测;不能凭想象认定系统性毁灭.局部损失可恢复时仍应做成本收益权衡.
- Confidence: medium

### convex-experiment-portfolio: 有限损失的凸性试验组合
- Definition: 试错有用的前提是失败代价有限,成功能被选择和保留;增加波动本身并不创造价值.
- Use when: 多个未知方向可用小试验筛选,成功成果有进一步使用的空间.
- Procedure: 写出单次损失上限和真实退出权,检查多个失败是否相互传染;以小尝试覆盖不同假设,设置可以改向的阶段;保留有效结果,记录负面结果及测试条件;扩大投入前重查损益结构,计入总试验费,等待和协调成本.
- Signals: 可逆性,每次成本,结果可复用性,退出自由,收益上限,失败相关性.
- Evidence: S01, S02
- Limits: 期权也可能太贵;虚假的低成本,隐性外部损害和不可隔离试验会破坏该结构.原文均分预算与增加次数的主张不是所有研发的最优公式;不直接外推为医疗或安全关键系统实地试验.
- Confidence: medium

## Decision heuristics
- 概率争论无解 -> 先看估错的后果 -> 无法存活的暴露先改造. [S01, S03]
- 提议更多尝试 -> 先验证损失可封顶 -> 只是增加重复风险时停止扩量. [S02]

## Tensions
- 保守地保护存续与积极地探索可以同时成立,前提是探索风险真正隔离.
- 局部凸性不能证明整个系统受益;应核对成本和损失是否转嫁给他人.

## Unknowns
- 不包含其私人交易参数;没有证明任意行业天然具有凸性,也不采纳来源中的医学或生物政策断言.
