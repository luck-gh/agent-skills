# 孙宇晨思维模型

## Best used for
- 评估加密产品的采用路径,现有网络整合,资源供给与贡献激励.
- 在思维风暴中提供商业落地与分发视角,检查叙事能否变成真实使用.

## Do not use for
- 代币买卖,收益承诺,用知名度推断信用,制造虚假活跃或隐瞒激励关系.
- 把本文件视为孙宇晨全部商业策略,或者把其宣传性的规模与性能陈述当作已独立验证的事实.

## Core models

### utility-before-adoption: 从实际用途降低采用门槛
- Definition: 让用户为已经需要的支付,传输或存储任务选择新网络,把采用理由具体化为费用,速度和操作负担,而非仅靠技术身份.
- Use when: 新平台的愿景清楚,用户仍缺少迁移动机.
- Procedure: 选一个正在发生的用户任务;分别比较完整成本,速度,控制权和操作负担,说明谁能制定或改变规则;确认迁移中哪些功能应由用户选择;用小范围真实使用验证任务完成与留存,分开验收宣布,交付和稳定效果.具体比较和实验步骤是当前操作化,不是本人固定方法原文.
- Signals: 完成任务所需步骤,实际费用与耗时,重复使用,补贴结束后的留存,用户能否说清新增价值.
- Evidence: S01, S02, S03
- Limits: 访谈中的性能与规模数字带有推广目的,本模型不采信为效果证据.费用优势不能替代安全,治理与服务可靠性核验;基础设施使用量不能直接推出代币价值.
- Confidence: medium

### network-incentive-bridge: 连接既有网络与贡献激励
- Definition: 以已有分发网络为入口,让新激励对准可验证的资源供给,形成用户体验改善与持续参与的连接.
- Use when: 平台有用户入口,但带宽,存储或内容供给缺乏持续动力.
- Procedure: 标出既有网络,实际需求者与供给者,识别原有激励已解决什么;找出缺失的有效贡献,明确谁付费与谁获益;分开观察持有奖励,新增用户补贴和正常资源交易;比较引入前后的实际消耗,供给质量及未参与者体验;贡献没有改善时调整或撤回激励.此处验证与停止条件为当前推断.
- Signals: 有效供给量,资源实际消耗,奖励与贡献的对应关系,新增用户完成任务的比例,无激励情况下的需求.
- Evidence: S02, S03
- Limits: Project Atlas 的方案和本人 AMA 支持方法意图与实施方向,不证明激励长期有效.既有用户数不等于可转化用户数;发放奖励也可能吸引刷量和短期套利.
- Confidence: medium

## Decision heuristics
- 宣称改变金融基础设施 -> 先落到一个具体支付或结算任务 -> 缺少端到端使用证据时保留为假设. [S01]
- 奖励持有人却没有新增资源供给 -> 检查能否转为有效贡献奖励 -> 不能建立贡献关系时停止扩大激励. [S02, S03]

## Tensions
- 宏大愿景有助于组织生态,但可验证的产品价值往往局部且有限;传播不能越过当前能力.
- 扩大网络与维持有效贡献会冲突;用户数量,交易数量和真实需求须分开判断.
- 减少中介控制与接入身份核验等治理规则需明确权力边界;“去中心化”一词不能替代规则设计或承诺核验.

## Unknowns
- 未核验其注意力投入的长期回报,私人谈判,内部成本,代币持仓及当前项目安全性.没有把社区总结的全仓下注或名人绑定升级为核心方法.
