# 瑞·达利欧思维模型

## Best used for
- 检查资产或业务组合背后的共同风险;区分长期配置与主动判断.
- 在方案碰撞后检查意见质量,反对理由与决策责任.

## Do not use for
- 承诺任何环境都不亏损,自动加杠杆,将观点数量当独立证据,强迫披露隐私.
- 把历史桥水组织实践直接当成任何团队都适用的管理制度.

## Core models

### balance-economic-exposures: 按经济驱动平衡风险
- Definition: 分散的对象是驱动损益的经济暴露,不是产品名称或投入金额;增长和通胀相对预期的变化可能同时冲击多项资产.
- Use when: 多资产或多业务组合看似分散,却担心一类环境变化造成共同损失.
- Procedure: 从支出,负债或服务承诺定义需要稳定的结果及风险中性位置;像鸡肉成本拆成饲料暴露那样拆出主要驱动,核对对冲与实际成本的剩余差异;区分已反映的预期与意外变化;检查增长和通胀升降情景;比较损失贡献及流动性,补足真正不同的暴露;将现金,长期市场暴露与主动预测分开.这是当前操作化,不输出通用配置比例.
- Signals: 风险贡献集中,相同现金流驱动,压力情景下相关性上升,期限错配,融资和再平衡成本.
- Evidence: S01, S02
- Limits: 两个经济维度不能覆盖违约,战争,治理或流动性风险.波动率和相关性会变;平衡风险不保证正回报,也不自动授权使用衍生品或融资.
- Confidence: high

### believability-weighted-disagreement: 用可信依据处理分歧
- Definition: 先保留各方独立判断,再根据相关领域的可核对经历和因果解释处理分歧,由明确责任者作出决定.
- Use when: 会议或思维风暴出现相反结论,权威地位或多数意见正在替代论证.
- Procedure: 先明确责任者与本类决策的否决权限;让各方独立陈述结论,依据与不确定性;定位分歧究竟在事实,因果还是目标;检查与当前任务直接相关的记录和解释,评价标准也须可信;多数与相关经验较强的少数相反时继续核对;用反例检验关键假设;由责任者说明取舍,保留待验证异议.不捏造数字化可信度评分.
- Signals: 可复核记录,因果链是否完整,愿意修订的条件,意见间共享的证据,最终责任者是否清楚.
- Evidence: S03, S04
- Limits: 名人过往成功不能给本次模拟答案增加可信度.多个语言模型输出可能高度相关,不能套用真人独立经验的权重;权限与资源不对等也会压制真实异议.
- Confidence: high

## Decision heuristics
- 持仓品种多 -> 检查相同环境下是否一起受损 -> 若依赖相同驱动,不能算充分分散. [S01, S02]
- 资深者和多数人意见相反 -> 比较相关依据与解释 -> 无法核对时保留不确定性,不按资历直接裁决. [S03]
- 负责人特别确信 -> 主动找有根据的反对意见 -> 无法回答关键质疑时降低承诺程度. [S03, S04]

## Tensions
- 全天候配置追求减少择时依赖,主动判断追求利用特定机会;混在一起会掩盖实际风险来源.
- 广泛表达与高效决策需要同时成立;允许异议不意味着无限讨论或责任消失.
- 风险中性取决于真实支出目标;现金名义稳定可能无法维持购买力.全天候是设计目标,本人家族与桥水的具体实现已分别演化. [S01, S02]

## Unknowns
- 桥水内部最新模型,具体仓位,风险估计和人员评价机制未公开核验.本文件不证明其组织制度的因果效果.
