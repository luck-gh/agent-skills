# Naval Ravikant 思维模型

## Best used for
- 专长产品化,可复用成果,合作对象选择与长期交易条件.

## Do not use for
- 保证财富回报,无限承担交易风险,把所有生活关系按金钱衡量.

## Core models

### specific-knowledge-leverage: 特定知识与可复制杠杆
- Definition: 优势来自难以直接标准化培训的知识组合,杠杆让一次正确判断惠及多次交付.
- Use when: 重复工作挤占了能创造差异价值的判断与创造.
- Procedure: 从已有成果及他人观察辨认擅长且愿意深入的任务,区分情境判断与可通用培训的基础技能;确认他人需要什么;选择代码,内容或产品等可重复交付形式;先用代表性任务检验质量,再比较新增覆盖,纠错与维护成本后扩大投入.步骤是当前操作化,工具版本或强弱标签不能代替结果验证.
- Signals: 独立解决问题的证据,使用者复用率,交付边际成本,纠错与维护时间.
- Evidence: S01, S02
- Limits: 杠杆同样放大错误.个人兴趣不是市场需求的证据,AI 工具的便利也不等于产出已经正确.
- Confidence: high

### trust-compounds: 信任与重复合作
- Definition: 在有重复机会的关系中,可信判断和公平交易减少未来摩擦;不适合的交易应尽早排除.
- Use when: 正在比较一次性收益与后续合作空间.
- Procedure: 写清双方真实需要和不可接受条件;明确自己知道与不知道的事实;核实后续合作机会是否真实;提出双方愿意重复接受的条件并主动指出不适配;区分可逆试用与难解除的长期绑定,检查资源是否允许拒绝;以阶段履约决定是否继续,对反复违约设置退出条件.这是据材料归纳的应用步骤.
- Signals: 承诺兑现率,信息是否准确,纠纷处理成本,对方是否愿意再次合作.
- Evidence: S03, S04
- Limits: 重复合作需要基本可信度与退出能力.一次违约获利远高于未来合作收益时,长期声誉未必约束行为.诚实不要求公开隐私或放弃谈判边界,长期关系也不能抵消持续伤害;不能捏造未来订单制造重复关系.
- Confidence: high

## Decision heuristics
- 工时线性增加而成果没有积累 -> 找一个可复用交付物 -> 先验证需求与质量再放大. [S01, S02]
- 一笔交易只有隐藏缺点才谈得成 -> 公开关键事实并检查适配 -> 不适配就退出. [S03, S04]
- 对方有长期声誉 -> 仍核实本次激励与履约 -> 单次背叛收益过高时不因过去关系而放松检查. [S03]
- 合作条件看似可以接受 -> 比较解除难度和被限制的未来选择 -> 难以退出时提高核验要求,可逆安排可小规模验证. [S04]

## Tensions
- 快速放大需要控制错误传播,长期信用要求承诺小于或等于交付能力.
- 慷慨的长期条件与对反复违约者设边界可以同时成立.

## Unknowns
- 不知道任何未公开投资,收益或当前商业安排.2026 年 AI 使用经验只支持杠杆方向,不保证具体工具效果.
