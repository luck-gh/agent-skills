# Judea Pearl 思维模型

## Best used for
- 业务实验,故障归因,干预效果评估,对看似合理的因果结论做复核.

## Do not use for
- 凭观察相关性宣布因果,将任意箭头图当证据,用模型替代临床或其他专业审查.

## Core models

### identify-before-estimate: 先定义因果问题再估计
- Definition: 数据回答什么取决于问题和因果假设;估计数值之前先证明所求量能由现有证据确定.
- Use when: 从采取某行动者的结果推断所有人采取该行动的效果.
- Procedure: 明确人群,实际行动,对照,时间和结果,区分随机分配与真正执行;区分观察,干预和个案反事实;画出机制及未知因素,列出识别这个查询所必需的假设;判断目标是否可识别并检查关键可检验约束;能识别才估计,不能则报告可支持界限及需要的实验或额外假设.
- Signals: 目标量定义,分组形成机制,未测共同原因,同样观察数据是否允许不同因果解释.
- Evidence: S01, S02
- Limits: 识别是对假设的条件结论,整体拟合好不能证明关键因果假设.反事实需要个案与结构信息,群体平均不能直接当个体答案;不依从会使实际行动仍受混杂.识别假设被推翻时重做分析,不能靠扩大样本消除结构不确定性.S01 与 S02 大量共享推导,高置信指方法在假设下的明确性,不是两次独立实验或对具体领域因果图的认证.
- Confidence: high

### graph-guided-adjustment: 由因果图选择调整变量
- Definition: 调整变量的作用由其在因果路径中的位置决定,不是控制越多越可靠.
- Use when: 拟用回归或匹配估计干预效果,候选变量很多.
- Procedure: 标出处理,结果,共同原因,中介与碰撞点;在有依据的有向无环图上检查后门路径;选不含处理后代且阻断全部后门路径的调整集合,不能逐个按相关性筛变量;多个集合均有效时比较测量成本,误差与方差;检查测量和重叠性,对遗漏关系做敏感性分析.找不到后门集时进一步检查其他识别途径.
- Signals: 路径方向,变量测量时点,未测混杂,碰撞点条件化,不同假设下的结论变化.
- Evidence: S01, S02
- Limits: 后门准则是充分条件,不穷尽所有识别方法;时变处理,选择偏差和循环机制需要进一步建模.
- Confidence: high

## Decision heuristics
- 样本量巨大但机制不清 -> 先问可识别性 -> 统计精度不能消除结构不确定性. [S01, S02]
- 想把所有变量放进回归 -> 先检查路径角色 -> 中介或碰撞点可能让目标改变或偏差增加. [S01]

## Tensions
- 清楚而简洁的模型便于批判,遗漏重要机制又会破坏结论;应暴露关键假设并比较替代图.
- 随机实验可降低部分识别负担,观察研究能否识别取决于额外结构与数据.

## Unknowns
- 本文件没有针对用户领域验证任何具体因果图,不提供自动识别或数值估计实现.
