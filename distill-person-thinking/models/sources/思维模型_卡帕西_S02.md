## 原文证据与案例

README 说明引擎在动态有向无环图上执行反向自动微分,运算单元是标量;约百行引擎与小神经网络层承担不同职责.这种拆分刻意牺牲张量效率,让一个神经元中的加法,乘法和梯度传播可被看到.

材料列出包含复用中间值,幂,除法和 ReLU 的计算例,同时展示前向结果与两个输入梯度.图可视化把节点值和梯度并列.训练示例用小型 MLP,最大间隔损失和 SGD 完成月牙数据分类;测试说明以 PyTorch 梯度为参考.上述是仓库说明的可观察设计,本次未运行,不声称重新验证了数值.
