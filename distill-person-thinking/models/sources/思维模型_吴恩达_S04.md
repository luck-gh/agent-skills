# 思维模型_吴恩达_S04: 把任务分析连接到采购或自建

## 原文证据与案例

吴恩达自述在 Davos 分享任务分析,据此讨论购买工具还是自建应用,自建可以是内部项目或衍生公司.他将直接使用聊天界面与通过 API 构建应用区分,也要求使用者学习安全有效使用,领导者亲自理解工具.这是现场应用框架的自述,没有报告某家企业最终采购或投资回报.

附言强调 AI 应用持续小改动可能有意外副作用,因此要建立随修改重复进行的验证.它为试点后的维护成本提供具体理由,并不证明所推荐课程或任何工具一定适合当前项目.

## 当前提炼与核心关系

据此归纳,先找高负担具体任务,再按工作流匹配程度判断已有界面是否足够,是否需集成或自建.将培训,接口交接,人工检查和修改后的回归验证计入总成本,比较实际净节省,避免用模型调用费用代替全部成本.

支持核心从任务分析到采购/自建的步骤.当前应用推断:用范围有限且可复核的试点比较方案,只在完整任务收益可测时推进;不是信中给出的固定 ROI 门槛.

## 局限与改判条件

其“多数知识工作者可立即更高效”是概括性观点,没有在本信附通用测量.当前改判条件:审查/集成成本吞掉局部提速,或者变更后关键质量下降时,缩小自动化范围或保留人工.2024 年提到的产品名不是当前采购建议.
