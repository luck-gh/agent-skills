# 彼得·林奇思维模型

## Best used for
- 从消费与工作经验发现研究线索;评估可理解公司的增长空间和经营变化.
- 在多模型比较中追问某个行业趋势最终能否转化为具体公司的盈利.

## Do not use for
- 用熟悉品牌替代财务研究,保证十倍收益,把美国历史市场表现外推为任何市场的必然规律.
- 用某个固定市盈率或增长比率自动产生买卖结论.

## Core models

### observation-to-research: 从熟悉观察走向公司研究
- Definition: 本地知识提供发现优势,投资资格来自进一步理解企业如何赚钱,财务是否支撑扩张及价格要求什么结果.
- Use when: 用户喜欢某种产品,观察到需求增长,但尚不知道公司是否值得投入研究或资本.
- Procedure: 用简单语言说明客户买什么及公司怎样获利;将观察列为待验证线索并给出下一步证据;核对盈利,财务状况,竞争与扩张空间,连锁业务区分尚未覆盖市场和接近饱和的市场;从目标市值与情景估值反推所需盈利,不沿用算例的固定倍数;只有证据支撑才形成判断.步骤为当前归纳,不等于本人逐字清单.
- Signals: 复购与扩张位置,利润来源,负债压力,新业务在整体中的占比,兑现价格所需的盈利.
- Evidence: S01, S02
- Limits: 单个门店或朋友圈容易偏样本;好产品可能只是大公司的一小部分.熟悉不能成为拒绝理解新业务的借口,林奇在 S01 承认因此错过 Amazon.
- Confidence: high

### story-over-price: 随经营故事更新判断
- Definition: 持有依据是企业尚能实现的盈利与改善路径;价格上涨不证明经营正确,价格下跌也不证明便宜或必然反弹.
- Use when: 原有投资理由正被行情或宏观噪声取代.
- Procedure: 写出原来预期的经营变化;比较最新盈利,财务与扩张事实;区分阶段性波动和核心逻辑破坏;重新检查价格隐含预期;依据事实保留,修订或放弃原判断.涉及实际资金时另行核对期限和承受能力.
- Signals: 扩张接近饱和,盈利质量恶化,改善证据出现或消失,财务能否撑到兑现,价格已预付的增长.
- Evidence: S01, S02, S03
- Limits: 长期持有需要仍成立的经营依据,不能把忍耐亏损本身当纪律.Bethlehem Steel 的再跌与 GE 超出原先增长判断分别要求放弃和修正旧故事.短期资金需求和永久性损失风险可能使等待不成立;S03 只谈历史整体市场,不能证明个股复苏.
- Confidence: high

## Decision heuristics
- 喜欢一家店 -> 加入研究名单并查看财务 -> 没有研究时不升级为投资结论. [S01, S02]
- 期待公司再增长十倍 -> 反推相应盈利和市场空间 -> 依赖不现实规模时放弃该预期. [S01]
- 只因股价大跌而认为便宜 -> 检查经营和生存条件 -> 缺乏改善证据时不借历史高价为自己辩护. [S01, S02]

## Tensions
- 容易理解与愿意学习之间需要平衡;既不追逐陌生热点,也不把旧知识边界当作永久禁区.
- St. Agnes 使用模拟资金且保留亏损项;可借鉴其解释业务后研究的过程,不能以课堂成绩证明方法胜率或直接复制持仓. [S02]
- 忽略短期价格噪声与持续复查公司并不冲突;前者保护耐心,后者防止对坏企业长期执念.

## Unknowns
- 未重建其完整六类公司策略或现时持仓,未提供可机械使用的估值阈值.原著中的成功样本不是方法有效性的独立统计证明.
