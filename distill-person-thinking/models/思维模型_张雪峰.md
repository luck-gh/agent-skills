# 张雪峰思维模型

## Best used for
- 在明确就业需求时比较教育路径的入口条件,时间成本及替代出路.

## Do not use for
- 以家庭条件否定个人兴趣,给专业永久排名,用过去的行业建议代替当年的招生章程和岗位要求.

## Core models

### career-backcast: 从职业入口倒推教育路径
- Definition: 先明确希望进入的职业与能承担的教育成本,再评估学校和专业能否抵达该入口,避免把录取本身当终点.
- Use when: 学校名气,热门专业和未来就业互相冲突.
- Procedure: 由学生本人确认工作与生活目标,列明可承担的年限和费用;反查真实招聘,区分专业/学历/资格的硬门槛与常见偏好;检查课程和学习准备,计入继续深造成本;产业政策只作线索,继续核对企业,岗位和毕业时间;按目标排序学校,城市和专业,列出首选不可达时的迁移路径.步骤为当前操作化.
- Signals: 招聘准入条件,课程与岗位技能的对应,继续深造成本,可迁移能力.
- Evidence: S01, S02
- Limits: 面向就业压力较明确的选择,不能以收入或家庭约束代替本人意愿.提前规划是提前获知条件,不是提前锁死选择.若目标偏研究或兴趣探索,应加入其他视角;门槛及行业判断需核对当前材料,不能把历史专业评价做成永久顺序.
- Confidence: medium

### ordinary-outcomes: 检查普通人的出路
- Definition: 以相近背景的常见就业去向检验教育选择,避免从少数成功者直接推导自己的前景.
- Use when: 宣传只有优秀校友,或者以为专业名称等于毕业后的职业.
- Procedure: 查相近学校,专业,地区和年份的毕业去向及统计口径;检查是否只呈现咨询客户或成功者;分开本专业就业,转行和深造;比较常见结果与不利尾部,核对对应职业入口,再与个人能力,偏好和代价对照.取样与比较步骤是当前操作化.
- Signals: 去向样本的覆盖范围,地区和年份差异,是否只展示头部案例,职业与专业的实际对应.
- Evidence: S01, S02
- Limits: 缺少可比统计时暂停外推;访谈中的任意中间区间,比例和薪资不是已核实分布,咨询客户也可能有选择偏差.群体结果用于校验风险,不能决定个人上限或否定有独立证据支持的路径.
- Confidence: medium

## Decision heuristics
- 只按专业名字选职业 -> 反查目标岗位的真实入口 -> 门槛未经核实时不承诺可达. [S01]
- 用顶尖校友证明专业适合自己 -> 补查相近条件下的普通去向 -> 样本不可比时停止外推. [S02]

## Tensions
- 就业可达性与兴趣探索可能冲突;需要把个人偏好及可承受试错成本明示,不能替用户决定.
- 及早规划能减少信息差,过早锁定单一路径也可能错失变化中的机会.

## Unknowns
- 未核验当前各省招生规则,具体院校就业率或收入数字.模型不预测录取,就业或个人发展结果.
