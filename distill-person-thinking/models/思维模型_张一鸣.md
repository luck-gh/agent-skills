# 张一鸣思维模型

## Best used for
- 团队扩张后的审批瓶颈,信息失真,岗位匹配与跨部门协作.

## Do not use for
- 把放权等同于放任,强制照搬特定公司组织结构,据此推断最新平台政策.

## Core models

### context-aligned-decisions: 用共享背景支持分布式判断
- Definition: 负责人提供问题背景和方向,让有能力且接近事实的人作判断,而非把自己当作唯一计算中心.
- Use when: 反复出现等批准,只执行不理解或各部门优化自己的局部结果.
- Procedure: 比较主管与一线拥有的信息,先判断问题来自背景,能力还是协调;共享目标,优先级,业务事实和过去失败;明确决策人与边界,保留横向专业协作;让相关成员补充证据并解释取舍;按结果修正背景.岗位职责按能力匹配,人员过渡另行处理.危机或新团队需要集中协调时约定退出条件,低成本测试也要比较等待导致的机会损失.
- Signals: 决策等待时间,成员能否解释取舍,重复报批,跨部门返工,所用事实是否一致.
- Evidence: S01, S02
- Limits: 高质量信息与判断能力是前提.仅把业务拆成独立团队可能加剧重复和协作成本,不能用放权逃避管理;成熟独立业务可另行评估分设单元.公开背景不要求公开敏感资料或取消一对一沟通.岗位问题也可能来自资源与目标冲突,不能直接归咎个人.
- Confidence: high

## Decision heuristics
- 同类决策反复升级 -> 先核对背景是否充分 -> 补背景后仍不能判断再处理能力或权限. [S01]
- 岗位与能力不匹配 -> 明确职责原则并调整岗位 -> 执行方式仍考虑人员过渡成本. [S02]
- 觉得方案已经确定 -> 用成本合理的事实检验复核 -> 窗口紧迫时不为讨论拖延. [S01, S02]

## Tensions
- 分布式决策提高信息覆盖,集中协调在危机和早期业务中可能更快.
- 原则清晰不等于处理僵硬,人员安排可以有过渡而不隐藏职责问题.

## Unknowns
- 公开材料不足以评估所有内部实施效果;不将组织自述当作独立因果证明.
