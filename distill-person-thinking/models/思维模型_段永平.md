# 段永平思维模型

## Best used for
- 企业与产品方向,停止错误投入,投资前的商业模式理解.

## Do not use for
- 推测个人当前持仓,复制集中仓位,将本分当成不经讨论的道德裁决.

## Core models

### right-direction-before-execution: 先分清方向错误与执行错误
- Definition: 先判断目标是否值得长期坚持,再优化实现方式;赚到短期收益不能证明方向正确.
- Use when: 团队只讨论怎样更勤奋,却没有检查事情本身是否有意义.
- Procedure: 分清最终消费者与渠道客户,说明长期价值和不可接受的手段;区分方向被证据否定和执行尚未学会,分别处理退出或学习;反复出现同类摩擦时检查交易规则与激励,估计制度建设期;依据持续行为逐步授权,定期检查原则与实际激励是否一致.
- Signals: 最终用户需求,长期代价,反复议价等制度摩擦,文化契合与能力的分别证据,能够纠正的执行缺口.
- Evidence: S01, S02
- Limits: 对错需具体理由,不能把个人偏好包装成普遍答案;停止投入仍须处理合同和受影响的人.
- Confidence: medium

### understand-business-before-price: 懂生意后看价格与波动
- Definition: 持有的信心来自对需求,产品,经营文化与现金来源的理解,而非对股价路径的信心.
- Use when: 研究被热点或价格变化牵着走.
- Procedure: 解释客户选择产品的原因和企业赚钱的方式;用实际行为核对文化,将个人信任与财务证据分开;列出不懂的变量及历史成功中的偶然条件;估计长期现金与买入成本是否相称;检查融资能否承受中途波动;经营假设失效时重审,不因等回本延后判断.
- Signals: 持续需求,产品差异,管理层说法与行动,现金创造,资金是否需短期取回.
- Evidence: S01, S02
- Limits: 熟悉产品不等于懂财务;信任某人不替代企业核验.不能用历史成功推出全仓或借款投资.
- Confidence: medium

## Decision heuristics
- 已发现逻辑错误却等回本 -> 从未来成本判断退出 -> 先确认错误是经营判断而非单纯价格下跌. [S01]
- 新热点很诱人 -> 先查是否真正理解 -> 允许错过,不要用必需资金追求额外收益. [S01]

## Tensions
- 尽早停止错误与容忍学习过程必须区分,否则容易在失败时放弃正确方向.
- 高度信任人与独立核验并存;真实关系信息不足时不能复制本人信任判断.
- 过去适用的跟随策略可能随企业阶段变化;创新应回应需求,但不能将个人不懂的早期研发判为普遍不值得做.
