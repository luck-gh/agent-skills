# Python 结构与流程

从实际 CLI/应用入口,装配函数和公开 API 定向读取.模块导入仅是静态关系,装饰器/插件表需查注册与调用位置.单进程内类和模块不自动画成独立服务.

- 接口记录函数/方法名称,关键参数,返回值/异常,可变对象所有权和副作用.类型注解是声明,不证明运行数据一定符合.
- `async def` 调用返回 coroutine,不是函数体已经完成.`await` 表示等待,不自动意味着启动新线程;`create_task` 才明确调度独立任务,其实际完成顺序仍可能未知.
- 区分同步回调,事件循环,线程,进程和队列.注册点本身不证明回调已发生.标明取消/超时/异常传播,没有实现的错误处理不补造.
- 缓存命中,未命中和异常分别看,存储是内存对象还是外部服务需要代码/配置依据.懒加载/运行时 import 和 monkey patch 只有出现且相关时才展开.
- 不运行被分析程序或导入模块来探测关系.不安装 AST/调用图框架来恢复完整语义;Agent 直接核对相关文件,动态部分保留条件和未知项.

draw.io 给出模块与关键连接;Markdown 用结构图,接口说明和必要的 alt/else/par 时序展开关键场景.
