# draw.io 速览

直接生成 UTF-8 未压缩 XML,无需中间 JSON,转换服务器或图片嵌入.新图先用简单方框,分组,箭头和一句话总结,不要把接口表塞进主图.只有已有文件或需要相同骨架时读取 [overview.drawio](../assets/overview.drawio),不要把模板内容当目标事实.

## 文件与布局

- 使用 `mxfile > diagram > mxGraphModel > root`,或单页裸 `mxGraphModel`.每页保留根 cell 0 与默认层 cell 1.只生成未压缩图源,不手写 Base64.
- 模块是带 `vertex="1"` 的 mxCell,连线是带 `edge="1"` 的 mxCell.同页 ID 唯一;模块用 `mod_...`,在 Markdown 使用同名 HTML anchor 与 Mermaid 节点 ID.注释和分组用 `note_...`,`group_...`.
- 节点有明确 x/y/width/height;沿 LR 或 TB 分层,宽度容纳中文标签,用留白而非缩小字体解决拥挤.分组子坐标相对于父容器,嵌套应核对父边界.
- 实际模块间的连接用 source/target 绑定节点,并有 `<mxGeometry relative="1" as="geometry"/>`.区分数据,调用,信号和条件关系;标签写动作,虚实含义写图例.
- 默认系统字体,浅底,清晰边界,正交连接,简短标签.尽量不使用外部图标,图片或需要额外字体的形状.
- 文本和属性正确 XML 转义,如 `&amp;`,`&lt;`,`&quot;`.普通文字优先 `html=0`;确需 HTML 标签时遵守转义,不嵌入脚本/外部资源.
- 多页重复同一模块时复用语义 ID 和名称;同一页不得重复.把低层细节放到 Markdown,主图完整体现分析范围而非罗列每个函数.

## 避免文字与连线遮挡

先确定信息层次,再安排模块,最后布线和放标签.不要把扫描所得调用图原样塞进速览.主图节点只保留模块名与一行职责,通常不超过 2-3 行;函数清单,地址/位宽,错误路径,证据和长条件说明放入 Markdown.省略的是主图细节,不是改变真实关系;不能为减少边数把直接调用改画为经中间模块调用.

- 新图建议节点文字 16-18,连线标签 14-16,不靠缩小字号或缩放整图来塞入页面.节点按最长一行及行数扩展,保留约 12-16 的内边距.画布尺寸是结果,不是必须挤满的一页限制.
- 用一致的 LR 或 TB 主方向,相邻层之间先预留约 80-120 的布线空间,多条边时加宽.容器标题单独占据顶部留白,不与子节点或穿越边共用区域.这些值是布局起点,不能代替实际阅读核对.
- 初始化/构建,运行控制,数据通路不要全部叠在同一排.主图突出当前问题的主要路径;需要保留较多关系时分为命名清楚的页面/视图,保持模块 ID 与 Markdown 对应.用户要求全量时用分组/多页完整保留,不暗中删除范围.
- 连线沿模块间的空白走廊走正交路径,不穿过无关节点或标题.回边从外围绕行,并行边使用分开的通道/端口;必要时设置显式 waypoints,不要假定正交样式会自动避开所有形状和文字.
- 每条边使用简短动作标签,如提交请求,触发中断,写寄存器.标签放在足够长的空白线段上,必要时单独偏移,不能压住节点文字,箭头端点或另一条标签.不要把完整函数签名写在线上;确需长说明时用短关系编号关联 Markdown 详解.
- 标签可用与画布一致的浅色背景隔开线条,但背景不能遮掉另一条关系或模块文字.缩短标签,移动标签,调整路径后仍拥挤时,增加间距或拆图,不以白底覆盖作为修复完成.

## 更新与检查

读取现有 XML 后局部修改,不要覆盖无关手调位置.既有 draw.io 可使用 object/UserObject 包裹节点;保留其自定义元数据.压缩图应通过现有编辑器另存为未压缩候选再检查,不自动安装解码/导出程序.

只读检查脚本不运行 draw.io,也不测量实际字体或自动连线路径.结构通过后,有现成 VSCode 插件或 draw.io 阅读能力时打开实际文件,分别在 100% 和适合页面视图复核:节点文字完整,标签之间/标签与节点不重叠,连线不穿文字,标题和图例有独立空间,主流程可辨.适合页面后文字过小,应精简主图或拆页而非仅增大画布.修改节点或连线路径后重新检查标签位置.

用户提供的遮挡截图是当前视觉失败证据,不能用 XML PASS 抵销.修改后的实际文件未经查看时只能报告布局已调整但视觉未复核,不能宣称遮挡已消除.缺少可用查看能力时交付候选并注明限制,不自动安装插件或发往在线编辑器.用户需要图片时才使用已可用的导出能力.

参考 [draw.io 官方生成与校验说明](https://www.drawio.com/docs/reference/diagram-generation/),[连线标签定位](https://www.drawio.com/docs/manual/connectors/),[连线拐点](https://www.drawio.com/docs/manual/connectors/waypoints-connectors/).本 Skill 的检查只是常见结构约束,不是完整 XSD/style 校验.
