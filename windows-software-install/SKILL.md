# Windows 大型软件安装

把“用户想要的结果”和“允许执行的动作”分开判断.保持过程可审计,可停止,可回滚;不要为了完成安装而猜参数,绕过安全检查或静默接受 C 盘默认路径.

## 选择工作模式

先声明当前模式;当请求不清楚时选择权限更低的模式.

### 仅规划

- 只输出候选版本,来源,目标路径,命令草案,风险,授权点和验证计划.
- 不下载,不运行安装器,不改注册表,服务,环境变量,文件或包管理器状态.
- 把未经官方资料确认的参数标为“待核实”,不要把草案写成可直接运行的确定命令.

### 只读审计

- 只检查现有文件,磁盘,已安装版本,签名,服务路径,卸载项和只读包清单.
- 不触发安装器的 repair,modify,自更新或 bootstrap;这些即使看似查询也可能写入系统.
- 记录证据来源和读取失败,不把“未发现”解释为“不存在”.

### 授权实施

- 仅在用户明确授权当前精确动作后进入.用户表达安装,升级或修复的目的,不等于授权实现该目的所需的后续动作.
- 对下载,校验,运行安装器,提权,接受许可,写目标目录,修改 `PATH`/环境变量/profile,创建快捷方式/服务/计划任务,重启,升级,修复和卸载分别建立门禁,并按实际目标逐项取得授权.不得把一项动作的批准传递给另一项动作或目标.
- 每次批准只绑定已展示的精确软件,版本,来源,哈希或其他可验证身份,动作,目标,参数和当前预检结果.任一字段或预检状态漂移时,原批准失效;暂停,重新说明并取得新授权.
- 配置,历史安装,已有目录,管理员身份,缓存安装包,命令可用性和先前批准都只是候选值或证据,不构成任何后续动作授权.
- 不得把"允许安装"泛化为未展示的附带组件,遥测,默认文件关联,系统配置或其他副作用.产品默认选择不明确时停止并报告,不要替用户选择.

## 确定适用范围

把 GUI 应用,IDE,SDK,开发套件,数据库,虚拟机,设备工具套件及大型客户端纳入本 skill.软件体积不明但可能包含大量资源,服务,驱动或全局集成时,也按大型软件处理.

排除以下请求:

- `npm`,`pip`,`cargo`,`dotnet`,`maven` 等项目或语言生态依赖;
- 仓库本地工具链,测试依赖和普通小型 CLI bootstrap;
- Windows Update,系统组件维护和仅需解压的便携工具.

若一个 bootstrap 随后会下载大型 GUI 软件或系统级工具链,则从它准备修改系统之前开始应用本 skill.

## 使用动作授权矩阵

| 动作 | 最低前提 | 是否单独暂停确认 |
| --- | --- | --- |
| 只读盘点,官方资料核对 | 与请求直接相关 | 否 |
| 下载已锁定版本的官方安装包 | 已说明精确身份,来源和暂存目标 | 是;仅授权本次下载 |
| 校验已锁定安装包 | 已说明校验对象,算法,预期身份和读取范围 | 是;不得沿用下载授权 |
| 执行安装,升级或修复 | 已说明精确安装器,操作,参数,目标路径和主要影响 | 是;每种操作和目标分别授权 |
| UAC,管理员权限或沙箱外执行 | 已说明为什么需要,将运行的命令及影响 | 是,使用平台审批机制 |
| 接受许可,附带组件,遥测或默认关联 | 已展示精确选项和影响 | 是;每项分别授权,默认值不明确时停止 |
| 写目录或修改 `PATH`,环境变量,profile | 已列出精确目标,值,作用域和恢复方式 | 是;每个目标分别授权 |
| 创建快捷方式,服务或计划任务 | 已列出精确对象,配置,运行身份和影响 | 是;每个对象分别授权 |
| 关闭应用,停止服务或终止进程 | 已识别精确名称,占用原因和业务影响 | 是;不要盲目 kill |
| 卸载旧版 | 已提供备份,回滚和保留用户数据方案 | 是;绑定精确旧版,卸载器,目标和参数 |
| 跨盘迁移中的写入或执行阶段 | 已逐阶段说明方案,目标和回滚 | 是;不存在可传递的整体"迁移授权" |
| 清理旧目录,备份或暂存/缓存 | 已列出精确对象和恢复影响 | 是;每个对象分别授权 |
| 覆盖非空目录,替换配置或共享组件 | 已列出将覆盖的确切对象和恢复方式 | 是 |
| 重启系统,注销或安排延迟重启 | 已解释必要性和未保存工作影响 | 是;永不擅自重启 |

用户拒绝,审批失败或无法交互时,停在安全边界并给出后续命令或选择;不要换一种方式绕过授权.

## 锁定安装身份

在下载或执行前锁定以下字段:

- 官方产品名和发布者;
- 精确版本或明确的版本策略;
- stable,LTS,preview 等渠道;
- x64,x86,ARM64 等架构及系统兼容性;
- 安装器类型,官方下载页或厂商仓库;
- 预期数字签名发布者;若官方提供哈希,再锁定哈希算法和值.

读取 [source-and-preflight.md](references/source-and-preflight.md) 完成来源,签名,哈希,磁盘,文件系统,ACL 和冲突检查.任何关键身份字段无法核实,签名无效或哈希不匹配时停止,不执行安装包.

## 选择 D 盘路径

只有已经声明工作模式,锁定本次软件为 x64 或 x86,并且当前工作确实需要目标路径时,才处理安装根.仅规划或只读审计不需要目标路径时,跳过本节,不读取 settings.

1. 优先使用用户为当前操作显式提供的对应架构根,不读取 settings.
2. 没有显式根时,从当前 physical skill dir 读取与 `SKILL.md` 同级的 `settings.json`.只选择当前架构对应的 `install_x64` 或 `install_x86`;不要读取,要求或验证另一架构的根.
3. Settings 缺失,损坏,含 unknown 字段,缺少当前字段或当前路径不可用时,按 [本地设置](references/local-settings.md) 只询问当前架构所需值,不得搜索其他位置.
4. 把实际选定的一个根以单键 JSON object 通过 stdin 交给 [installation-root preflight](scripts/check_install_roots.py),不得把路径放入 argv;只有固定输出为 `ok` 才继续.

Settings 值只是路径候选,不证明路径当前可用,也不授权下载,校验,执行,提权,写目录,安装,修改系统,重启或清理.Root checker 只核对当前 D 盘,fixed/local/online/NTFS,SUBST,目录,reparse 和规范路径;按 [source-and-preflight.md](references/source-and-preflight.md) 完成 ACL,动态容量,冲突及其他安装前检查.

通用 skill 不提供作者或机器特定的物理默认值.保留厂商默认相对层级和产品版本命名,只替换程序文件根目录;发布者不明确时先核实,不要猜厂商目录.

不要修改全局 `ProgramFilesDir` 注册表值,不要移动 Windows 的 Program Files,不要用 junction 或符号链接伪装位置.

允许驱动,Windows 功能,Microsoft Store 托管内容,运行库,Installer 缓存,共享组件,以及必须进入 `System32`,`ProgramData` 或 `AppData` 的少量系统托管文件留在系统位置.若大型主体或大量数据不可避免地进入 C 盘,执行前暂停,给出预计位置和占用并取得明确同意.

## 准备可审计执行

读取 [execution-and-recovery.md](references/execution-and-recovery.md) 建立执行记录并处理受支持参数,显式路径,有界超时,日志,退出码,升级,修复,迁移,回滚和恢复.未知参数或退出码按未验证处理;包管理器和官方安装器都不能可靠控制主体路径时暂停.

## 保护秘密传输

本节是不可由安装器习惯,执行记录模板或引用文件示例放宽的硬门禁.

- API key,token,账户或代理凭据,激活材料及其他秘密不得拼入 shell 文本或 command 字段/草案,不得作为 argv 或参数数组传递,不得写入日志,普通文件,配置模板或回复.脱敏只用于最小化意外捕获的证据,不是安全传输方案,也不能消除已经发生的暴露.
- 优先使用经验证的 provider 或厂商官方认证流程,系统凭据存储,或厂商明确支持且不会暴露到进程列表的通道.工具或 provider 声称会保存凭据,本身不能证明其使用了安全存储;无法验证时报告证据边界,不要断言安全.
- 安装器只支持通过弱 argv 或命令行接收秘密时,不要静默接受.明确说明进程列表,历史和日志暴露风险,先查找厂商支持的安全通道;仍无安全方式时 fail closed.风险接受不能授权绕过这项硬禁令;用户最多决定停止或改用不传递秘密的其他受支持机制,不得实际传递秘密.
- 短期 token 和确认材料只保留在当前操作内存中,最小化读取与保留时间,并对输出和诊断证据脱敏.不得持久化或复用于后续动作.

## 升级,修复与迁移

按 [execution-and-recovery.md](references/execution-and-recovery.md) 定位现状,备份,分阶段授权并准备恢复.不要假设升级会迁移,不要手工搬动已安装目录;修复与安装采用相同核验和授权门禁.

## 验证完成条件

安装器退出后按 [verification-and-reporting.md](references/verification-and-reporting.md) 完成分层验证和结构化报告.版本,架构,实际路径或适用的 smoke test 未验证时,不要报告“安装成功”;需要重启才能完成时保持“待重启”,先取得重启授权.
